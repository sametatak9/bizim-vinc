# Bizim Vinç v1.3 — Operasyon akışları

## Dashboard (Mobofis tarzı)
- KPI: toplam personel, mesaide, giriş yapmayan
- Hareketler feed (activity_events) — profil foto ile
- Bekleyen talepler = Approval Center özeti (sekmeli)
- Şu an: izinli / fazla mesai / görevli
- Üst menü korunur (sol sidebar yok); widget grid yeşil-beyaz DS

## Operatör = saha terminali
- Üyelik + avatar_url / photo
- Mobil: yoklama, yakıt, mesai, makbuz, pre-use → approval_requests + activity_events

## Vinç görevlendirme
1. Havuzda operatör + yağcı seç
2. crane_assignments oluştur (crane + customer + site)
3. pool_status: havuzda → gorevli; vinç → sahada
4. Harita: assignment map_lat/lng + customer

## İş başı
- Buton: kartvizit linki + job_contracts PDF
- outbound_messages: email ve/veya WhatsApp
- Taraflar imzalar → contract status signed
- İmzalanmadan iş resmi başlamaz (onay kuralı)

## İş sonu
- Operatör makbuz: started_at, ended_at, cari, lokasyon, quote_id
- approval_requests(makbuz) — teklif satırları ile birleşik payload
- Admin Onay → job_receipts resmi + invoice adayı
